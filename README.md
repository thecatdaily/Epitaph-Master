# 贞珉录 · 传统墓碑碑文与墓志铭智能撰写 Skill (Epitaph Master)

精通中国西南（黔、桂、湘）及华南地区民间传统碑刻规制，输入白话生平、生卒年月及立碑人关系，自动生成符合传统丧葬堪舆规制的墓志铭、黄道合吉中榜及配对墓联。

## ✨ 核心特性
- **五步法经典叙事**：世系溯源 ➔ 初诞辰刻 ➔ 行谊风范与白话转译 ➔ 考终享寿 ➔ 卜穴立铭。
- **宗规严格判定**：严格遵循“长辈在世用先不用显”（先考/显考）宗法礼俗。
- **黄道合吉校验**：自动核算中榜有效汉字（生老病死苦 5 字小黄道，西南 12 字大黄道）。
- **生平模糊文言化**：将木工手艺、务农、经商、局弈丝竹、捐钱修路、课子读书等白话文自动转为醇正文言。
- **全量 24 副传统古联库**：内置横批与上下联。

## 🚀 多平台安装与调用指南

### 1. 在 豆包工作台 / 扣子 (Coze) 中使用
1. 打开扣子平台创建智能体或插件。
2. 在「插件 (Plugins)」菜单中点击 **「创建插件」** ➔ 选择 **「基于 OpenAPI 规范导入」**。
3. 直接上传本项目仓库中的 `openapi.yaml` 文件。
4. 将 `prompts/system_prompt.md` 的内容粘贴至智能体的 **提示词 (Prompt)** 输入框中即可。
